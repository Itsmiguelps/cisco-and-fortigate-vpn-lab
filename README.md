# cisco-and-fortigate-vpn-lab
Laboratorio de implementación de VPNs utilizando Cisco y FortiGate. Incluye IPSec IKEv1/IKEv2 (Policy-Based, Route-Based y GRE over IPSec), DMVPN Fase 2 y Fase 3, L2TP/IPSec Client-to-Site, y VPN Site-to-Site y Client-to-Site en FortiGate, con pruebas de conectividad mediante traceroute.
