1. IPsec de sitio a sitio: basado en políticas

Cifrado decidido por ACL (tráfico interesante) y aplicado con crypto map en la interfaz WAN. No hay interfaz de túnel.

Dirección


R1: G0/07.41.1.1/24 (LAN A) · G0/1200.0.0.1/30 (WAN, puerta de enlace 200.0.0.2)
R2: G0/07.41.2.1/24 (LAN B) · G0/1200.0.0.5/30 (WAN, gw 200.0.0.6)
ISP: G0/0200.0.0.2/30 · G0/1200.0.0.6/30


R1 — IKEv1--------------------------------------------------------------
--------------------------------------------

hostname R1

interface e0/0
 ip address 7.41.1.1 255.255.255.0
 no shutdown

interface e0/1
 ip address 200.0.0.1 255.255.255.252
 no shutdown
exit

ip route 0.0.0.0 0.0.0.0 200.0.0.2

crypto isakmp policy 10
 encryption aes 256
 hash sha256
 authentication pre-share
 group 14
 lifetime 86400

crypto isakmp key cisco123 address 200.0.0.5

crypto ipsec transform-set TSET esp-aes 256 esp-sha256-hmac
 mode tunnel

ip access-list extended VPN-ACL
 permit ip 7.41.1.0 0.0.0.255 7.41.2.0 0.0.0.255

crypto map CMAP 10 ipsec-isakmp
 set peer 200.0.0.5
 set transform-set TSET
 set pfs group14
 match address VPN-ACL

interface e0/1
 crypto map CMAP
