VPN hub and spoke punto a multipunto DMVPN Fase 3 con IKEv2 con enrutamiento dinámico

-----------------------------------------------------
Hub
------------------------------------------------

hostname HUB

interface e0/0
 ip address 7.41.40.1 255.255.255.0
 no shutdown
interface e0/1
 ip address 200.0.0.1 255.255.255.252
 no shutdown
ip route 0.0.0.0 0.0.0.0 200.0.0.2

crypto ikev2 proposal IKEV2-PROP
 encryption aes-cbc-256
 integrity sha256
 group 14
crypto ikev2 policy IKEV2-POL
 proposal IKEV2-PROP
crypto ikev2 keyring KR
 peer ANY
  address 0.0.0.0 0.0.0.0
  pre-shared-key cisco123
crypto ikev2 profile IKEV2-PROF
 match identity remote address 0.0.0.0
 authentication local pre-share
 authentication remote pre-share
 keyring local KR

crypto ipsec transform-set TSET esp-aes 256 esp-sha256-hmac
crypto ipsec profile DMVPN-PROF
 set transform-set TSET
 set ikev2-profile IKEV2-PROF

interface Tunnel0
 ip address 10.0.1.1 255.255.255.0
 no ip redirects
 ip mtu 1400
 ip nhrp authentication NHRPkey
 ip nhrp map multicast dynamic
 ip nhrp network-id 1
 ip nhrp redirect
 ip tcp adjust-mss 1360
 no ip split-horizon eigrp 100
 ip summary-address eigrp 100 7.41.0.0 255.255.0.0
 tunnel source e0/1
 tunnel mode gre multipoint
 tunnel key 100
 tunnel protection ipsec profile DMVPN-PROF

router eigrp 100
 network 10.0.1.0 0.0.0.255
 network 7.41.40.0 0.0.0.255
 no auto-summary
